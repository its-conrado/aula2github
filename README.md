## Código em Linha e Blocos de Código

Use uma crese para destacar um comando ou trecho curto no meio de uma frase.

O comando `git status` mostra o estado atual do repertório.

O comando `git add .` adiciona os arquivos modificados a *staging area*.

O comando `git comit -m "Texto com a descriação do que foi implementado"` registra as alterações com uma mensagem

O comando `git push`sobe as alterações para a nuvem.

```
git status 
git add .
git comi
git commit -m "Texto com a descriação do que foi implementado"
git push origin main

```
